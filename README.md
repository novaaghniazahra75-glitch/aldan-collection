# ALDAN COLLECTION

Final group project for the Algorithm Programming course (Semester 1).

## Description

ALDAN COLLECTION is a console-based inventory management application developed using Python. The program helps manage women's fashion product inventory by providing CRUD operations, stock management, and transaction history reports.

## Features

- Login Authentication
- Add Product
- View Product List
- Update Product
- Delete Product
- Incoming Goods
- Outgoing Goods
- Transaction History Report
- Pagination
- Sorting Transaction Report

## Technologies

- Python 3
- Datetime Module
